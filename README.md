## Contenido
Proyecto Android de ejemplo en Kotlin + XML para la Práctica 6. Extrae textos y colores a recursos, define estilos reutilizables, soporta colores nocturnos y permite cambiar el tema desde el botón.

## Abrir
1. Abre Android Studio y selecciona **Open**.
2. Selecciona la carpeta raíz del repositorio.
3. Espera a que Gradle sincronice. Si solicita descargar el SDK o componentes compatibles, acepta.
4. Ejecuta en un emulador o teléfono Android.
